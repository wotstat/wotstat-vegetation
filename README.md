# WotStat Vegetation

Мод для отображения колиженов растительности используемых в системе маскировки. Позволяет изучать их расположение, форму и поведение. Исследовать "дырки" в кустах и разбираться в неожиданных засветах.

> [!NOTE]
> Мод работает только в `Реплеях` и `Тренировочных боях`. В соревновательных режимах (Случайные, Клановые, Командные бои) мод не будет работать.


![Demo](.github/assets/demo-1.jpeg)

> По просьбе разработчиков игры я закрыл исходный код этого мода, чтоб минимизировать риск его использования в непредназначенных целях. Сам мод скомпилирован в безопасный бинарный `pyd` файл, разобраться в котором намного сложнее, чем в обычном `Python` моде.

## Установка
1. Скачайте файл мода [`wotstat.vegetation_1.0.0.mtmod`](https://github.com/wotstat/wotstat-vegetation/releases/latest).
2. Поместите их в папку `Tanki/mods/{АКТУАЛЬНАЯ_ВЕРСИЯ_ИГРЫ}/`.

## Использование

- `F2` - Показать/Скрыть колижены растительности.
- `F3` - Показать/Скрыть только маскирующие колижены.

### Значение цвета колижена
Цвет колижена зависит от его маскирующих свойств:

- `Зеленый` - добавляет 50% маскировки.
- `Желтый` - добавляет 25% маскировки (обычно это деревья без листвы).
- `Красный` - колижен не маскирует, но при этом существует в игре (обычно это трава и деревья далеко за границей карты). Одно и тоже дерево может быть как маскирующим, так и нет, этот параметр определяется индивидуально для каждого экземпляра.

### Локальный просмотр карт

Мод совместим с модом [WotStat Map Viewer](https://github.com/wotstat/wotstat-map-viewer) для локального просмотра карт. Просто установите мод и его настройки отобразятся в параметрах просмотра.
